# FOMO – From Distraction to Focus

## 🔗 Project Summary 

**FOMO** is a self‑awareness driven productivity platform that helps users overcome distraction and anxiety by converting FOMO into focused action through timers, progress tracking, journaling, and guided support.

## 🧠 Problem Statement

Modern users want to grow and stay productive, but constant distractions, comparison, and information overload create **FOMO (Fear of Missing Out)**. This leads to:

* Difficulty starting tasks
* Inconsistent focus
* No visibility of real progress
* Repeating the same distraction patterns

Most productivity tools focus only on *tasks* or *time*, not on *behavior and awareness*.

## 💡 Solution

FOMO is designed as a **focus companion**, not just a task manager.
It creates a simple loop:
**Focus → Reflect → Track Progress → Improve**

By combining focus tools with reflection and visual feedback, the platform helps users build sustainable productivity habits without pressure.

## ✨ Key Features & Why They Exist

### ⏱️ Focus Timer (Pomodoro + Manual)

**Why:** Long tasks feel overwhelming and stop users from starting.

**What it does:**

* Pomodoro mode breaks work into short, achievable sessions
* Manual timer supports flexible workflows

**Problem it solves:**

* Reduces overwhelm
* Trains consistent focus


### 📈 Progress Tracking

**Why:** Users often feel unproductive because progress is invisible.

**What it does:**

* Tracks focus time and activity
* Displays small wins clearly

**Problem it solves:**

* Builds motivation through visible progress
* Encourages consistency

### 📓 Journaling

**Why:** Distraction is often caused by mindset, not workload.

**What it does:**

* Allows users to reflect on focus sessions
* Helps identify distraction patterns

**Problem it solves:**

* Improves self‑awareness
* Prevents repeating the same mistakes


### 🤖 Guided Chatbot (Support System)

**Why:** Users feel stuck or demotivated and need instant guidance.

**What it does:**

* Asks simple, supportive questions
* Provides emotional and productivity guidance

**Problem it solves:**

* Reduces decision fatigue
* Makes users feel supported


### 🎨 Calm UI & Smooth Animations

**Why:** Productivity apps often feel stressful or boring.

**What it does:**

* Uses smooth scrolling and minimal visuals
* Reduces cognitive overload

**Problem it solves:**

* Improves engagement
* Encourages repeat usage


## 🔄 User Journey

1. User starts a focus session
2. Tracks progress automatically
3. Reflects through journaling
4. Identifies patterns and distractions
5. Builds better focus habits over time


## 🛠️ Tech Stack

* HTML, CSS, JavaScript
* GSAP for animations
* Locomotive Scroll for smooth scrolling


## 🎯 Impact

* Converts anxiety and distraction into focused action
* Encourages mindful productivity instead of pressure
* Helps users build long‑term focus habits

## 🚀 Future Enhancements

* AI‑powered insights from journal entries
* Personalized focus recommendations
* Advanced analytics dashboard

## 📌 Final Note

FOMO is not about doing more tasks — it is about **understanding yourself better to work smarter**.
